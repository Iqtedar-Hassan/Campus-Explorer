# Campus Explorer 🎓

**Campus Explorer** is a Flutter-based mobile application designed to help users explore university facilities through a clean, interactive, and user-friendly interface. The application demonstrates Flutter UI components, animations, screen navigation, and different scrolling layouts.

## ✨ Features

- **Splash Screen:** Animated welcome screen using Flutter animation widgets.
- **Home Screen:** Displays a welcome section and featured campus facilities.
- **Explore Facilities:** Browse campus facilities through a scrollable list.
- **Facility Details:** View individual facility information with Hero animations.
- **About Screen:** Displays application information and feature cards.
- **Drawer Navigation:** Navigate between the main sections using a navigation drawer.
- **Bottom Navigation Bar:** Switch between Home, Explore, and About screens.
- **Animated UI:** Uses AnimatedContainer, AnimatedCrossFade, and AnimatedOpacity.
- **GridView:** Displays six feature cards in a grid layout.
- **CustomScrollView:** Uses SliverAppBar and SliverList for a structured scrolling experience.
